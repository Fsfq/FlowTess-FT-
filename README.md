# FlowTess (FT)

Казуальная мобильная игра на стыке классического Тетриса и механики Block Blast, написанная на Jetpack Compose с кастомным мультиплеером через Epic Online Services (EOS).

## Что внутри

- **Классический режим**: привычный стакан, возрастающая скорость падения фигур, очистка линий и подсчет очков.
- **Block Blast**: поле, куда выставляются случайные блоки из предложенного пула фигур. Без таймера спешки, упор на комбо и зачистку доски.
- **Мультиплеер (EOS P2P)**: лобби, поиск соперника и матчи 1 на 1 в реальном времени. Интеграция сделана нативно через C++ EOS SDK и JNI-мост: лобби, обмен пакетами действий и состояния доски между игроками без выделенного игрового сервера.
- **Профиль и кастомизация**: профиль игрока, скины блоков, темы интерфейса, анимации и звуковые эффекты.
- **Кейсы и лут**: внутриигровая рулетка с шансами дропа предметов разной редкости (common, rare, epic, legendary).
- **Синхронизация**: сохранение прогресса, рекордов и инвентаря в Firebase Realtime Database и Firestore с оффлайн-кешем в локальной базе данных.
- **Рекламная монетизация**: интеграция Yandex Mobile Ads (Rewarded видео за награды).

## Стек технологий

- **Платформа**: Android (Kotlin, Jetpack Compose, Material 3)
- **Архитектура**: MVVM, Kotlin Coroutines, StateFlow
- **Сеть и бэкенд**: Epic Online Services SDK (C++ / JNI), Firebase (Auth, Firestore, Realtime Database)
- **Локальное хранилище**: SQLite / Room, DataStore
- **Звук**: встроенный кастомный саунд-движок для эффектов и музыки главного меню
