## English (EN)

### 1. General Provisions
The data controller is FsFqX (developer FsFq, contact email: fsfqx77@gmail.com). This Privacy Policy governs the processing and protection of user information within the FlowTess mobile application for Android.

### 2. Processed Data
* **Local Data**: Game configuration, high scores, unlocked cosmetics, and player stats are stored locally in the on-device SQLite database (Room) and system preferences.
* **Account Data**: When voluntarily registering via Firebase, the app processes unique user ID (UID), email address, display handle, and avatar tokens.
* **Network Telemetry**: Peer-to-peer multiplayer matches utilize Epic Online Services (EOS) relay servers without exposing public IP addresses to opponents.
* **Financial Information is not collected**: All transactions utilize in-game virtual currency.

### 3. Purpose of Processing
Information is processed solely to operate game functionality: persisting gameplay state, syncing leaderboard scores, validating anti-cheat determinism, and restoring player accounts upon verified request.

### 4. Third-Party Services
The full build interacts with Google Firebase, Epic Games EOS, and Yandex Mobile Ads SDK. In the offline edition (FlowTess Lite), all network stacks are disabled: no telemetry, cloud calls, or third-party transmissions occur.

### 5. Data Security
Sensitive preferences are hardware-backed and encrypted via Android Keystore (AES-GCM). Portable .FTB backup files require HMAC-SHA256 integrity signatures. User passwords are never stored in plain text.

### 6. User Rights
Users retain the right to reset local data at any time via in-game settings or request complete permanent deletion of their cloud profile and credentials by contacting fsfqx77@gmail.com.
